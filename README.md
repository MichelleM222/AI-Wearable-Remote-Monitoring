# AI-Powered Wearable Remote Monitoring System

### Intelligent Healthcare Monitoring Using IoT, Big Data, and Artificial Intelligence

## Project Overview

This project presents the design of an intelligent remote patient monitoring system integrating wearable devices, IoT connectivity, Big Data infrastructure, Machine Learning, and AI-powered alert management.

The proposed solution aims to collect physiological data, analyze patient-specific patterns, identify relevant events, and support timely communication with patients, caregivers, and healthcare professionals.

Developed as a final academic project for the Specialization in Artificial Intelligence and Data Analytics at Universidad de Caldas.

## Problem Statement

Traditional healthcare monitoring often depends on periodic measurements and in-person assessments.

Continuous remote monitoring can provide additional information about physiological changes and support earlier identification of relevant events.

## Proposed Solution

The proposed architecture integrates:

- Wearable sensors for heart rate, SpO2, temperature, movement, and location.
- Edge Computing for local processing and fall detection.
- BLE and mobile connectivity for data transmission.
- API-based ingestion and streaming.
- Big Data storage using a Bronze, Silver, and Gold architecture.
- Machine Learning for anomaly detection.
- An LLM-based agent for contextualizing alerts.
- Dashboards and notification mechanisms.

## System Architecture

Wearable Sensors → Edge Processing → BLE / Mobile App → API Ingestion → Data Lakehouse → Machine Learning → AI Alert Agent → Dashboard and Notifications

## AI Component

The proposed intelligence layer combines:

1. Anomaly detection based on individual patient baselines.
2. Rule-based event identification.
3. An LLM agent for alert contextualization and summarization.
4. Feedback mechanisms for reviewing alerts.

## Project Scope

This repository documents the proposed architecture, technical design, and academic project.

The architecture is a conceptual proposal; production deployment and clinical validation are not claimed.
